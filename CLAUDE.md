# Working on Family To-Do

- Every change people will notice gets a "What's new" note: add an entry at the
  top of `src/changelog.js` (plain words, one or two sentences, `at` = when it
  ships, `href` to the screen it's about). Notes show in the activity feed on
  every phone after the update. Pure refactors and invisible fixes don't need one;
  small fixes can share a note.
- Run `npx vitest run` and `npm run build` before pushing.
